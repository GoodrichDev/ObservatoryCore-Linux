Plugin Missing or Disabled - Hecate

What is Hecate?

Hecate is a Data Vault plugin whose purpose is the storing and retrieving data for other plugins.
This means that instead of each plugin having to maintain it's own background database of information, it can be store in a centralised location.
It also means API calls to spansh or similar services can be made just once and shared between plugins instead of each plugin making it's own requests.

Do I need it?

It's not required, but certain features won't work without it.
